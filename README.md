# Martı Kaçışı (Martıya Simit) 🕊️🥨

İstanbul Boğazı temalı, Flappy Bird esintili modern HTML5 Canvas oyunu.

🎮 **Canlı Oyna:** [https://serhanco.github.io/MartiyaSimit/](https://serhanco.github.io/MartiyaSimit/)

---

## 🌊 Özellikler

- **İstanbul Atmosferi:** Kız Kulesi, Boğaz Köprüsü, Şehir Hatları vapuru, tarihi yalılar ve Galata Kulesi silüeti.
- **Dinamik Gün Döngüsü:** Puan kazandıkça günbatımından alacakaranlığa ve yıldızlı geceye uzanan yumuşak geçişler ve kademeli yanan şehir ışıkları.
- **Özgün Türk Müziği & Ses Efektleri:** Tone.js tabanlı, Hicaz makamında 9/8'lik aksak ritimli ney, saz ve darbuka sentezleyicisi.
- **Akıcı Fizik & Oynanış:** 60 FPS sub-frame interpolasyon, parçacık efektleri, simit toplama bonusları ve skor kaydı.
- **Geliştirici Modları:** Bot modu (`B` tuşu) ve Hitbox hata ayıklama modu (`H` tuşu).

---

## 🚀 Yerel Olarak Çalıştırma

Projeyi yerel ortamda çalıştırmak için herhangi bir HTTP sunucusu yeterlidir:

```bash
# Bağımlılıkları yükleyin (testler için)
npm install

# Yerel sunucu başlatın
npx serve .
# veya
python3 -m http.server 8080
```

Tarayıcınızda `http://localhost:8080` adresini açarak oynayabilirsiniz.
